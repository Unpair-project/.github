# UNPAIR – Understanding Parasite-Host Networks

## About this repository

This repository provides public access to materials, resources and outputs developed within the **UNPAIR – Understanding Parasite-Host Networks** project.

It aims to share the scientific contributions and resources generated throughout the project, making available information and materials that can be publicly disseminated.

The repository will be progressively updated as new outputs become available.

## About the project

UNPAIR investigates parasite-host interactions across Brazilian biomes and ecoregions, exploring how environmental, climatic, land-use and socioeconomic factors influence the structure and spatial distribution of these interactions.

By integrating ecological network approaches with information on host immunological characteristics and parasite virulence factors, the project aims to advance our understanding of parasite-host relationships and their implications for biodiversity conservation and One Health.
